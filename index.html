Git v/s Github

| Git | GitHub | | ------------------------------------------------- | ------------------------------------------------------------------ | | Git ek **Version Control System (VCS)** hai. | GitHub ek **online platform** hai. | | Git computer me locally kaam karta hai. | GitHub internet par kaam karta hai. | | Git code ke changes ko track karta hai. | GitHub code ko online store aur share karta hai. | | Git se commit, branch, merge karte hain. | GitHub se repository, Pull Request, Issues etc. manage karte hain. | | Git use karne ke liye Git install karna hota hai. | GitHub use karne ke liye GitHub account chahiye. | | Git internet ke bina bhi use ho sakta hai. | GitHub ke liye internet connection chahiye. |

GitHub ka use kyon karte hain?

Code Store — Project ko online save karne ke liye. Backup — Computer kharab hone par code GitHub par safe rehta hai. Collaboration — Multiple developers ek project par kaam kar sakte hain. Version History — Code me kya changes hue, unki history dekh sakte hain. Branching — Alag features par independently kaam kar sakte hain. Pull Request — Apne changes ko review aur merge karwa sakte hain. Issues — Project ke bugs aur tasks manage kar sakte hain. Open Source — Public projects me contribute kar sakte hain.
