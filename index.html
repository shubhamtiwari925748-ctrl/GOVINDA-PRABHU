Git v/s Github

| Git | GitHub | | ------------------------------------------------- | ------------------------------------------------------------------ | | Git ek **Version Control System (VCS)** hai. | GitHub ek **online platform** hai. | | Git computer me locally kaam karta hai. | GitHub internet par kaam karta hai. | | Git code ke changes ko track karta hai. | GitHub code ko online store aur share karta hai. | | Git se commit, branch, merge karte hain. | GitHub se repository, Pull Request, Issues etc. manage karte hain. | | Git use karne ke liye Git install karna hota hai. | GitHub use karne ke liye GitHub account chahiye. | | Git internet ke bina bhi use ho sakta hai. | GitHub ke liye internet connection chahiye. |
